# Traknus Battery Simulator — Streamlit

## Deploy on Streamlit Community Cloud

1. Sign in at [share.streamlit.io](https://share.streamlit.io/) with the GitHub account that owns this repository.
2. Choose **Create app** and select `azariasyahla/traknus-battery-simulator`.
3. Set branch to `main` and app file path to `streamlit_app/app.py`.
4. Choose a URL name if available, then deploy. Streamlit installs the packages from `streamlit_app/requirements.txt`; customers open the resulting link in a browser and do not install Python.

The existing GitHub Pages `index.html` remains available separately.
