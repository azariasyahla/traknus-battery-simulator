# Traknus Battery Simulator

**Repository name:** `traknus-battery-simulator`

**GitHub description:** Interactive forklift battery runtime simulator for shift schedules, breaks, charging, and battery comparisons.

Simulasi interaktif untuk memperkirakan masa pakai baterai forklift berdasarkan model truk, kapasitas baterai, work intensity, jadwal shift, waktu istirahat, dan kesempatan charging.

## GitHub Pages

1. Upload `index.html` ke root repository.
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
5. Setelah proses publish selesai, bagikan link GitHub Pages kepada customer.

Aplikasi berjalan sebagai HTML statis. Customer cukup membuka link melalui browser; tidak perlu menginstal Python atau Streamlit.
