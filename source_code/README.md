# Source code — Traknus Battery Simulator

- `index.html` berisi struktur tampilan dan data model baterai.
- `styles.css` mengatur tampilan, termasuk tata letak cetak PDF.
- `app.js` berisi logika simulasi, interaksi, grafik, dan laporan.
- `safe-storage.js` menangani penyimpanan preferensi bahasa.

Simpan semua file dalam folder ini bersama-sama. Untuk versi siap buka tanpa mengatur file, gunakan `../index.html` di folder utama ZIP.

Aplikasi ini menggunakan HTML, CSS, dan JavaScript; tidak memerlukan Python atau Streamlit.
